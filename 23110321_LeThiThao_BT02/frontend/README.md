# Tour Profile Client

React + Vite client for the tour profile feature.

## Setup

1. `cd client`
2. `npm install`
3. `npm run dev`

The app will start on `http://localhost:3000` and proxy `/api` to `http://localhost:5000`.

## Usage

- Paste a valid JWT token into the token box.
- Save the token to load the current profile.
- Edit profile fields and save changes.
