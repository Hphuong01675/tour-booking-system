# Frontend Tour Booking System

Ứng dụng React + TailwindCSS kết nối với backend Node.js.

## Cài đặt

1. Mở terminal tại `client`
2. Chạy `npm install`
3. Chạy `npm run dev`

## Khởi động backend

Trong thư mục gốc của dự án, chạy `npm start` để khởi động backend tại `http://localhost:6969`.

## Tính năng

- Trang landing `http://localhost:5173/`
- Trang login `http://localhost:5173/login`
- Gọi API backend `/api/login` bằng Axios
- Quản lý trạng thái đăng nhập bằng Redux Toolkit
